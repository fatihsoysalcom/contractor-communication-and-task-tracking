# Contractor Communication and Task Tracking

This Python script simulates a project management system to track tasks, contractor feedback, and communication logs. It highlights how clear communication and status updates are crucial for identifying and resolving issues with contractors.

## Language

`python`

## How to Run

Save the code as `contractor_tracker.py` and run it from your terminal using: `python contractor_tracker.py`
